🎯 Objetivo do Aplicativo

O Lactare Connect é um aplicativo Android desenvolvido em Kotlin e Jetpack Compose com foco em saúde. Seu principal objetivo é otimizar e incentivar a doação de leite materno, conectando doadoras a bancos de leite humano parceiros e redes de apoio a neonatos. O app facilita desde a verificação de elegibilidade até o agendamento de coletas e o acompanhamento por meio de uma interface moderna e intuitiva.

🛠️ Instruções para Executar o Projeto

Para clonar e executar o projeto em sua máquina utilizando o Android Studio, siga os passos abaixo:

Pré-requisitos:

Ter o Android Studio instalado (versão recente com suporte ao Kotlin 2.0+ e Compose).

JDK configurado (versão 17 ou superior).

Clonar o repositório:

Bash git clone https://github.com/carlosvillarinho/LactareConnect.git

Abrir no Android Studio:

Abra o Android Studio, selecione Open, e escolha a pasta raiz do projeto clonado (LactareConnect).

Aguarde a sincronização automática do Gradle (caso necessário, clique em Sync Project with Gradle Files).

Executar:

Inicie um Emulador Android configurado no AVD Manager.

Clique no botão Run (ícone de play verde ▶️) na barra superior do Android Studio.
